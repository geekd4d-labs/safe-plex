# SAFE PLEX project context

Before changing this repository:

1. Load the `safe-plex-gen5w` skill.
2. Read `docs/maintainer-context.md` for the current release state, decisions,
   validation boundary, pending work, and recovery commands.
3. Read `docs/device-validation.md` before making any safety or compatibility
   claim.
4. Preserve the fail-closed Park Guard. Missing, malformed, contradictory,
   stale, or unreadable telemetry must block Plex.
5. Run `python3 tools/test_all.py`; for package changes, build twice and compare
   both inner and USB archives before publishing.

The repository and release artifacts are the source of truth. Do not infer that
an archive was physically vehicle-tested merely because its runtime lineage was.
